# Материалы и крафты — план v0.1

> Состояние на 2026-08-04, ветка `dev`. Документ фиксирует замысел до реализации.

## 1. Отправная точка

Что есть сейчас:

- **Осколок Разлома** (`rift_shard`) — единственный материал мода. Падает с успешного
  коллапса разлома, `1–3` штуки. Тратится ровно в одном рецепте — Синхронизационный узел.
- **Рецептов всего один** — узел. Ноутбук, док, карманный Кодекс, диагностическая капсула
  и флешка **не крафтятся**, то есть вход в основной контент недостижим в выживании.
- **Двенадцать мировых блоков не дропаются**: шесть блоков Контура и по три блока каждого
  межпространства не имеют лут-таблиц и при добыче не дают ничего.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Как игрок получает Кодекс | **Находка + починка**, не крафт с нуля |
| Передел Осколка Разлома | Через **новый блок-обработчик** |
| Броня Рифтволкера | **Не трогаем.** Личная вещь под UUID автора, модель под переделку |

## 3. Хребет материалов

```text
ваниль ──┐
         ├─► Резонансный стабилизатор (блок)
Осколок ─┘            │
Разлома               ▼
                Резонансное ядро ──┐
                                   ├─► техника Кодекса, узел
жила Межпространства РНА ─► РНА-проводник ─┘
```

### Новые предметы

| Предмет | Откуда | Роль |
|---|---|---|
| **Резонансное ядро** | передел Осколка в стабилизаторе | «мозг» любой техники мода |
| **РНА-проводник** | жилы Межпространства РНА | проводящая часть, привязывает измерение к прогрессии |
| **Повреждённый полевой ноутбук** | сундуки ванильных структур | находка-триггер всей ветки Кодекса |

### Новый блок

**Резонансный стабилизатор** — превращает сырой Осколок в Резонансное ядро.

Осколок — сырая аномальная материя, её нельзя класть напрямую в тонкую электронику; отсюда
передел. Работает сам по себе на времени, но **Синхрон может ускорить процесс примитивом
Стабилизация (P5)** — это связывает систему сил с производством, не делая РНА обязательной.
Жёстко гейтить нельзя: игрового способа получить РНА пока нет вовсе.

## 4. Ветка Кодекса: находка и починка

Лорно техника достаётся от предшественников, а не собирается на верстаке. Это ложится на шаг
прогрессии «старые сигналы → первая запись».

1. **Повреждённый полевой ноутбук** подкладывается в сундуки ванильных структур —
   древний город, крепость, бастион. Своих структур у мода нет, а инъекция в чужие лут-таблицы
   даёт нужное ощущение без их постройки.
2. **Починка**: повреждённый ноутбук + Резонансное ядро + РНА-проводник + медь → рабочий ноутбук.
3. Остальное уже крафтится обычным путём, потому что игрок «разобрался в технологии»:
   карманный Кодекс, док, диагностическая капсула.
4. **Флешка** остаётся находкой — это носитель чужих данных, а не деталь.

## 5. Черновые рецепты

Ориентир по дороговизне — существующий рецепт узла (железо, медь, аметист, редстоун, осколок).

```text
Резонансный стабилизатор     камень + железо + Осколок Разлома
Резонансное ядро             Осколок Разлома → (стабилизатор) → ядро
РНА-проводник                добыча жилы Межпространства РНА + переплавка
Ноутбук (починка)            повреждённый ноутбук + ядро + проводник + медь
Карманный Кодекс             проводник + ядро + железо + аметист
Док                          проводник + железо + ядро
Диагностическая капсула      ядро + проводник + железо + стекло + редстоун
Синхронизационный узел        существующий рецепт — перевести с Осколка на Ядро
```

## 6. Лут-таблицы, которых не хватает

Минимум — блоки должны выпадать сами при добыче:

- Контур отбраковки: `contour_stone`, `contour_surface`, `contour_trace`, `contour_stone_vein`,
  `contour_weeping_stone`, `contour_vein`;
- Межпространство РНА: `rna_interspace_stone`, `rna_interspace_surface`;
- Межпространство Рифтволкера: три блока по аналогии.

Отдельно: **жила Межпространства РНА** должна давать сырьё под РНА-проводник, а не саму себя.

## 7. Порядок реализации

1. Лут-таблицы двенадцати блоков — самое дешёвое и чинит явную дыру.
2. Резонансное ядро, РНА-проводник, стабилизатор + его рецепт и логика.
3. Повреждённый ноутбук + инъекция в сундуки + рецепт починки.
4. Рецепты остальной техники Кодекса.
5. Перевод рецепта узла на Ядро.

## 8. Осознанно отложено

- Материалы Контура отбраковки — измерение секретное, ветка поздняя.
- Материал Межпространства Рифтволкера — пока незачем, броня не делается.
- Всё, что связано с бронёй Рифтволкера.
- Огранки и Апекс не требуют материалов: они тренируются, а не крафтятся.

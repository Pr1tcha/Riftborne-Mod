# Черновики: Барьер и телекинез

Здесь лежит рабочий код Барьера и телекинеза, снятый с коммита `a50434f` —
последнего состояния **перед** сносом старой системы сил (коммит `23f3675`).

Папка `drafts/` **не входит в сборку**: gradle компилирует только `src/main/java`,
так что этот код лежит мёртвым грузом и ничего не ломает.

## Важное предупреждение

Это код **мёртвой модели V2 («производные аспекты»)**. Он завязан на удалённые
`RnaApi`, `RnaData`, `RnaAbilityData`, реестр техник и аффинити-теги — то есть
**вернуть его копипастом обратно нельзя**. Возвращать нужно осмысленно, переложив
на PS V2.5:

- **Барьер** по канону V2.5 — это не отдельная «способность», а **Огранка**:
  примитив Стабилизация (P5), переогранённый через защитную Грань. Формулы
  прочности, поглощение урона, перехват снарядов и Veil-визуализацию из `drafts/`
  можно брать почти как есть — менять надо слой доступа (кто и на каком основании
  может это применять) и стоимость (через `LoadCalculator`, а не собственный
  расчёт износа).
- **Телекинез** концептуально уже заменён примитивом **Сдвиг (P3, ΔG)**. Из
  черновика полезны механика удержания/подтягивания цели, бросок и клиентский
  ввод — как основа для будущей Огранки Сдвига.

## Что внутри

| Папка | Что |
|---|---|
| `barrier/java/` | фазы и жесты Барьера, клиентское состояние, Veil-поле, миксин подавления взмаха руки |
| `barrier/assets/` | пост-эффект и шейдер поля барьера (Veil/pinwheel) |
| `barrier/BASIC_TECHNIQUE_BARRIER.md` | исходное ТЗ техники: формулы прочности, сектор защиты, освоение |
| `telekinesis/java/` | способность, команда, сеть, клиент, рендер и сущность поднятого блока |
| `telekinesis/Telekinesis.md` | исходное описание |
| `shared/` | общий движок способностей, на котором оба держались: менеджер, реестр, данные, кулдауны, модификаторы стадий |

## Как посмотреть исходное состояние целиком

Файлы здесь вырваны из контекста. Если нужно увидеть, как всё работало вместе:

```bash
git show a50434f --stat
```

```bash
git checkout a50434f -- src/main/java/com/pr1tcha/riftborne/rna/combat
```

Второй командой старый пакет вернётся в рабочее дерево целиком — но **сборка
сломается**, потому что его зависимостей больше нет. Для просмотра лучше
`git show`, а не `checkout`.
